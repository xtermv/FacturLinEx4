2. Se crea pnlNav alineado a la derecha dentro del pie.
3. Anterior / Siguiente / Cancelar tienen posiciones fijas dentro de pnlNav.
4. Se fuerza BringToFront del pie y navegación para evitar solapamiento GTK/LCL.
5. El cuerpo pasa a TScrollBox para que la página de datos de tienda pueda
   desplazarse en pantallas de menor altura.
6. Se aumenta ligeramente la altura inicial del asistente.

No se modifica:

- MariaDB;
- datos mínimos;
- lógica de instalación;
- VeriFactu;
- sudoers.

lazbuild -B InstaladorGUI/FLXInstaller.lpi
./Bin/FLXInstaller

Anterior aparece deshabilitado en el paso 1, que es correcto.
