14.1 Criterio de actualización #

Cada versión estable de un módulo debe indicar si cambia un procedimiento, un atajo, una pantalla o un dato utilizado por el usuario. Cuando exista un cambio, se actualizará el capítulo afectado, su figura y la tabla de control de versiones.

  • Conservar la edición estable anterior.
  • Identificar el módulo y procedimiento modificados.
  • Actualizar texto, imagen, cuadros, números y leyendas de forma conjunta.
  • Renderizar y revisar todas las páginas afectadas.
  • Sincronizar DOCX, PDF y versión web.
  • Añadir una línea al control de versiones.
