ESTADO

Basado en la versión validada clientes_moderno_v2_fix13_selector_formulario_facturas.zip.

3.1 Acceso y foco inicial #

Al abrir el formulario de Clientes, el foco debe situarse en el campo Código, que es el punto de entrada principal. Esto permite consultar o crear clientes sin utilizar el ratón.

  • ESC cierra el formulario desde la página principal.
  • Si existe un selector, diálogo o edición pendiente, ESC debe atender primero ese elemento.
  • Los grids permiten ordenar por columnas y muestran el sentido de ordenación.

3.2 Consultar un cliente #

  1. Escribir el código si se conoce y confirmar.
  2. Utilizar la búsqueda por nombre, razón social, NIF o datos relacionados cuando no se conozca el código.
  3. Revisar la ficha completa antes de modificarla, especialmente condiciones fiscales, tarifas y opciones de facturación.
  4. Comprobar documentos asociados desde los selectores o pestañas disponibles.

3.3 Crear un cliente #

El código propuesto debe respetar la misma lógica utilizada por Ventas y por la ficha de Clientes. Antes de guardar, debe comprobarse que el cliente no existe con otro código.

  • Código correcto y no duplicado.
  • Nombre o razón social completo.
  • NIF/CIF/DNI/NIE revisado.
  • Dirección, población, provincia y código postal.
  • Teléfono y correo electrónico.
  • Forma de pago y condiciones comerciales.
  • Serie o circuito de facturación cuando proceda.
  • Opciones especiales C41, C42, C55, C56 y C57 revisadas cuando sean aplicables.

3.4 Coincidencias de NIF #

Cuando un NIF coincide con más de un cliente, no debe seleccionarse automáticamente el primer registro. Debe mostrarse una ventana con todas las coincidencias para que el usuario elija la entidad correcta. Este caso aparece con frecuencia en entidades públicas, grupos relacionados o fichas históricas.

i
BUENAS PRÁCTICAS

No utilizar únicamente el NIF para decidir el cliente. Comparar también nombre, dirección, centro, departamento y código interno.

3.5 Cliente a precio de coste #

La opción asociada al campo C57 permite identificar clientes cuyas ventas deben calcularse con precios de coste, por ejemplo para consumo propio. Esta función requiere una revisión fiscal cuidadosa y debe comprobarse en Ventas antes de utilizarla de forma general.

i
PENDIENTE DE VALIDACIÓN COMPLETA

La lógica comercial puede estar implementada, pero el tratamiento del IVA, márgenes, descuentos, estadísticas y documentos debe comprobarse en cada circuito.

3.6 Modificación y borrado #

Antes de modificar datos fiscales o comerciales, debe revisarse si el cliente tiene documentos pendientes. El borrado físico de clientes con histórico puede afectar consultas y trazabilidad; cuando sea posible, es preferible desactivar o marcar la ficha en lugar de eliminarla.

3.7 Lista de comprobación #

  • El foco entra en Código.
  • La búsqueda general se abre centrada y permite ver el formulario de origen.
  • Las columnas ordenan correctamente.
  • Los botones de búsqueda y rutas son visibles.
  • Las opciones críticas no quedan ocultas.
  • ESC vuelve al menú sin cerrar diálogos de forma insegura.
